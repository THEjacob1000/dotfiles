# How to get frontend design right

When a change affects how an interface looks, moves or reads, or replaces hand-rolled web UI code with a platform feature, use the `frontend-design` skill before editing. It routes the task to one maintained upstream skill and pairs web work with Modern Web Guidance. Changes that leave both the rendered result and the UI mechanism alone don't need it.

The user's brief and the project's existing design system take precedence over upstream taste. Build from the project's existing components and tokens, extending them rather than restyling one page on its own.
