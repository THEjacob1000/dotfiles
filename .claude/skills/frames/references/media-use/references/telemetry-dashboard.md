# Media-use usage dashboard: unavailable upstream service

The upstream dashboard depends on its resolver telemetry and an authorized HyperFrames PostHog analytics project. Numen does not emit those events or provide a dashboard-creation or `resolve --stats` equivalent for them. Do not manufacture data or use unrelated mounted analytics tools to create a dashboard without an explicit request and a real event source.

The upstream questions are invocation volume, media-type mix, resolver hit rate `hits / (hits + misses)`, provider mix, top missing media types, dependency-check failure mix, comparison costs/timeouts and optional first-run adoption. Its event family is `media_use_resolve`, `media_use_resolve_miss`, `media_use_candidates`, `media_use_doctor_run`, `media_use_compare`, `media_use_transcribe`, `media_use_duck` and `media_use_transcript_cut`; these are source reference names, not guaranteed Numen events.

Upstream identity is pseudonymous before sign-in and account-linked afterward via a shared HyperFrames install id and HeyGen account. Upstream coarse properties omit intent text, filenames and paths, and set `$ip:null`. None of that establishes Numen's own telemetry policy. Before any separately authorized integration, confirm actual event/property schemas and privacy requirements; the missing event source remains a prerequisite, not a reason to silently approximate counts from media files.
