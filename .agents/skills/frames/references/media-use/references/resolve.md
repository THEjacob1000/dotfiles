# Asset resolution

Remote asset search for BGM, SFX, images, icons, official logos, and fonts remains unavailable. Keep supplied assets local and record metadata with `frames.media_index {"project": "/absolute/path/to/project", "record": {"type": "image", "path": ".media/images/hero.png", "source": "local", "description": "Approved hero"}}`; registration allocates an id under the project lock, skips an unchanged current-path record, rounds duration to 0.1 seconds, and regenerates the inventory. Local cube validation, ingestion, and parametric generation use `frames.lut`; preferences and approved recipes use `frames.media_prefs` and `frames.media_recipe`. For visual grading/treatments use `frames.media_treatment` and `frames.grade_compare`.
