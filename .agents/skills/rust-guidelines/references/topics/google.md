# Google Rust guidance

Read [API design context](../google-sections/api-design-context.md#api-design-context)
first when deciding which library or application rules apply. Then use the
[detailed section navigation](../navigation/google.md) to select the relevant
bounded excerpts. Each excerpt preserves its pinned source text and identifies
the revision and license. Do not load the entire guide for a narrow decision.

Google is primary after user instructions, repository constraints and the local
policy. Platform-labelled rules apply only to their named platforms. Preserve
exceptions, existing public contracts and the local overrides for typed errors
and non-exhaustive APIs. The section navigation contains the full scope and
precedence guidance, the decision table, and canonical source provenance.
